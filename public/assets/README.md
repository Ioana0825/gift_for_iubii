# Assets

Drop your real files in here with these exact names (or update the paths
in `src/content.ts` if you'd rather rename them):

- `our-video.mp4` — your video. Until it's added, the site shows an
  elegant "video coming soon" placeholder instead of a broken player.
- `memory-1.jpg`, `memory-2.jpg`, `memory-3.jpg`, `memory-4.jpg` — photos
  for the "Pieces of us" step. Until an image exists, that memory shows a
  soft glowing placeholder instead of a broken image icon.

Add more memories by adding another object to the `memories` array in
`src/content.ts` — the layout adapts automatically.
